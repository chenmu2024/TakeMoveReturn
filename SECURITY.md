# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **support@takemovereturn.com**.

Do not include passwords, worker PINs, authentication cookies, Supabase service-role keys, Waffo private keys, or other production secrets in an issue or public discussion.

Include only the minimum information needed to reproduce the problem: affected URL or feature, expected behavior, observed behavior, and non-sensitive reproduction steps.

## Scope

High-priority reports include cross-tenant access, authentication or authorization bypass, anonymous QR mutation, worker-session bypass, billing entitlement manipulation, secret exposure, unsafe file handling, and destructive privacy or retention behavior.

Public GitHub issues are appropriate for non-sensitive bugs and feature requests, but not for security reports.
